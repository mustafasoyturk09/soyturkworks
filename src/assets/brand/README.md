# Soyturk Works SW amblemi

Kullanıcının verdiği metalik SW görselinin şeffaf sürümü, yerleşik `image_gen` aracıyla hazırlandı. CLI veya API anahtarı kullanılmadı. Şeffaf çıktı kırpılıp standart web simgesi boyutlarına küçültüldü.

Dosyalar: `sw-logo.png` (512 px), `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `favicon.ico` ve `apple-touch-icon.png` (180 px).

Kullanılan son görsel düzenleme istemi:

> Remove only the black/gray background and outer halo from this supplied Soyturk Works SW emblem. Keep the exact S and W geometry, overlapping arrangement, silver metallic highlights, navy blue circular badge, bevels, proportions and fine edges. Deliver the complete emblem centered with a small transparent margin, on a genuinely transparent background. No redesign, no extra text, no extra objects, no added background or outer glow. This cutout will be used as the company's website logo and favicon.
